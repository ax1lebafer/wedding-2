# Анкета гостя → Google Таблицы

Ответы с сайта пишутся в Google Таблицу через **Google Apps Script** (без своего сервера).

## 1. Создайте таблицу

1. Откройте [Google Sheets](https://sheets.google.com) и создайте новую таблицу.
2. В первой строке укажите заголовки:

| A | B | C |
|---|---|---|
| Дата и время | Имя и Фамилия | Присутствие |

## 2. Добавьте скрипт

1. В таблице: **Расширения → Apps Script**.
2. Удалите код по умолчанию.
3. Скопируйте содержимое файла [`scripts/google-sheets-rsvp.gs`](../scripts/google-sheets-rsvp.gs) в редактор.
4. Сохраните проект (иконка дискеты), имя любое — например `Wedding RSVP`.

## 3. Опубликуйте веб-приложение

1. Справа сверху: **Deploy → New deployment**.
2. Тип: **Web app** (шестерёнка → Web app).
3. Настройки:
   - **Execute as:** Me (ваш аккаунт)
   - **Who has access:** Anyone
4. Нажмите **Deploy**.
5. При первом деплое разрешите доступ к аккаунту Google (Review permissions → Advanced → Go to … → Allow).
6. Скопируйте **Web app URL** (вида `https://script.google.com/macros/s/.../exec`).

> Если меняете код скрипта позже: **Deploy → Manage deployments → Edit (карандаш) → New version → Deploy**.

## 4. Подключите URL к сайту

1. В корне проекта создайте файл `.env` (рядом с `package.json`):

```env
VITE_GOOGLE_SCRIPT_URL=https://script.google.com/macros/s/XXXX/exec
```

2. Подставьте свой URL из шага 3.
3. Перезапустите dev-сервер (`npm run dev`) — Vite читает `.env` только при старте.

Для продакшена добавьте ту же переменную в настройках хостинга (Vercel / Netlify / и т.д.).

Пример переменной без секрета: см. [`.env.example`](../.env.example).

## 5. Проверка

1. Откройте сайт, заполните анкету, нажмите **Ответить**.
2. Должно появиться: «Спасибо! Ваш ответ записан».
3. В таблице появится новая строка с датой, именем и вариантом присутствия.

## Если не работает

- **«Форма ещё не настроена»** — нет `VITE_GOOGLE_SCRIPT_URL` или сервер не перезапущен.
- **Ошибка отправки** — проверьте, что доступ веб-приложения = **Anyone**, и после правок скрипта создана **New version** деплоя.
- Откройте Web app URL в браузере — должен вернуться JSON `{"result":"ok"}` (это `doGet`).
